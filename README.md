# nixos-config

Declarative multi-host NixOS configuration template using nix flakes, featuring [home-manager](https://github.com/nix-community/home-manager) for dotfiles and [sops-nix](https://github.com/Mic92/sops-nix) for secrets management

Includes: KDE Plasma 6, Pipewire, NVIDIA drivers, laptop power management, gaming environment (Steam, Lutris, Gamemode), and home-manager dotfiles (Zsh, Starship, Kitty, Git)

> this is a **generic template** intended to be used as a starting point
> Clone or fork this repository and complete the checklist below before applying it to a machine

---

## Quick start checklist

Complete these setup steps before building your system:

1. **Set your username**
   change `username = "changeme"` in `flake.nix`.
   > *this automatically updates `users.users`, home manager, and shell configurations*

2. **Configure your user profile**
   - **Display Name:** update `description = "change me"` in `modules/users/user.nix`
   - **Git Credentials:** set your name and email in `home/user/programs/git.nix`
   - **Initial Password:** generate a hash using `mkpasswd -m sha-512` and set `hashedPassword` in `modules/users/user.nix` or configure via SOPS

3. **Set hostnames & hardware**
   - **Hostnames:** update `networking.hostName` in `hosts/desktop/configuration.nix` and `hosts/laptop/configuration.nix`
   - **Hardware config:** replace the placeholder `hardware-configuration.nix` in each host folder with the output generated by `nixos-generate-config`

4. **Adjust system defaults**
   - **Locale and timezone:** adjust `modules/system/locale.nix` *(default: America/Sao_Paulo / pt_BR / ABNT2)*
   - **System packages:** add or remove packages in `modules/system/packages.nix`
   - **Secrets management:** update `.sops.yaml` with your age key *(see [`secrets/README.md`](./secrets/README.md))*

## Repository structure

```text
**`flake.nix`**: flake entry point containing system configurations (desktop and laptop) and shared modules

**`hosts/`**: host specific definitions and machine generated hardware configurations

**`modules/`**: reusable nixos modules broken down by domain:
  `system/`: bootloader, locales, fonts, base packages, and SOPS integration.
  `desktop/`: KDE Plasma 6 setup, Pipewire audio, and gaming tools
  `hardware/`: gpu drivers (nvidia), 3d graphics, and laptop power management
  `users/`: base system user creation

**`home/`**: home manager configuration containing user level dotfiles (Zsh, git, kitty)

**`secrets/`**: encrypted credentials managed declaratively with sops-nix
```

Shared modules in `modules/` are included in `commonModules` inside `flake.nix`
Individual host definitions extend this base with hardware-specific configs

## First time installation

1. Complete the **checklist** above

2. Copy the system generated `hardware-configuration.nix` to the target host folder:

   ```bash
  cp /etc/nixos/hardware-configuration.nix ./hosts/desktop/hardware-configuration.nix
  # or for the laptop:
  cp /etc/nixos/hardware-configuration.nix ./hosts/laptop/hardware-configuration.nix
   ```

3. (Optional) configure encrypted secrets by following
   [`secrets/README.md`](./secrets/README.md).

4. Generate or update the `flake.lock` file:

   ```bash
   nix flake lock
   ```

5. Apply the system configuration 
   The name after the `#` must match with the key picked in `nixosConfiguration` (`desktop` or `laptop`):

   ```bash
   sudo nixos-rebuild switch --flake .#desktop
   # or
   sudo nixos-rebuild switch --flake .#laptop
   ```

## Daily use

- test changes without applying them permanently:
  ```bash
  sudo nixos-rebuild test --flake .#desktop
  ```
- update all flake inputs (like `Nixpkgs, Home Manager, SOPS`):
  ```bash
  nix flake update
  ```
- update a specific input:
  ```bash
  nix flake lock --update-input nixpkgs
  ```
- rollback to the previous generation:
  ```bash
  sudo nixos-rebuild switch --rollback
  ```
- edit encrypted secrets:
  ```bash
  nix develop   # enters devShell with `sops` installed
  sops secrets/secrets.yaml
  ```

The default `update` Zsh alias simplifies re-building your system 
Adjust the repository path in `home/user/programs/shell.nix` if cloned outside of `~/nixos-config`

## Adding a new host

1. Create a new directory under `hosts/<hostname>/` containing `configuration.nix` and `hardware-configuration.nix`

2. Add a new `nixosSystem` target entry under `nixosConfigurations` in `flake.nix`

## Gaming notes

- `programs.steam.enable` manages firewall configuration, 32 bit library dependencies, and gamescope session support

- use `protonup-qt` to manage custom Proton releases (such as Proton-GE)

- add `mangohud %command%` to Steam launch options to display dynamic performance overlays

## Laptop notes

- battery charge thresholds (`START_CHARGE_THRESH_BAT0 / STOP_CHARGE_THRESH_BAT0 in modules/hardware/laptop-power.nix`) require supported hardware
remove these keys if unsupported by your vendor

- laptops with hybrid GPUs (NVIDIA Optimus) require additional configuration (`hardware.nvidia.prime`)

## CI

The `.github/workflows/check.yml` workflow runs `nix flake check` and dry-build evaluations on every pull request and push to catch syntax and module errors early

## Security guidelines

- never commit `~/.config/sops/age/keys.txt` or any private key files to git (enforced via `.gitignore`).

- `secrets/secrets.yaml` is safe to commit **only after** encryption through `sops`.

- review `hosts/*/hardware-configuration.nix` for sensitive disk UUIDs or serial numbers prior to pushing to public repositories

## Future improvements

- add [nixos-hardware](https://github.com/NixOS/nixos-hardware) as a flake input to handle model-specific laptop quirks
